# Contexto do projeto

- Este projeto é o backend de um sistema de bibliotecas.
- Está em estágio inicial de desenvolvimento; considere isso ao propor soluções e evite presumir requisitos ou funcionalidades ainda não implementados.
- A aplicação é desenvolvida em Java com Spring Boot e expõe uma API REST.

# Orientações para agentes

- Antes de implementar, confira a estrutura e os padrões já existentes no backend e mantenha as alterações consistentes com eles.
- Para mudanças no banco de dados, verifique as migrations existentes e altere-as antes de criar uma nova migration.
- Crie uma nova migration somente depois de avaliar e alterar as existentes, quando isso ainda for necessário para atender à mudança.
- Faça alterações focadas no escopo solicitado e valide-as com os testes ou verificações disponíveis no projeto.
